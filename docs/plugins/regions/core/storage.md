# Storage

This plugin will add the `_regions` namespace to the map to hold its region effects data.

## Parent

- The map.

## Addition

The `_regions` namespace.

## Save Section

`regions`, when `J-Base-Save` is installed. Without it, the namespace saves inline with each parent in the normal save.
