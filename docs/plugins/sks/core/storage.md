# Storage

This plugin will add the `_sks` namespace to the actors to hold their equipped skill slots.

## Parent

- All actors.

## Addition

The `_sks` namespace.

## Save Section

`sks`, when `J-Base-Save` is installed. Without it, the namespace saves inline with each parent in the normal save.
