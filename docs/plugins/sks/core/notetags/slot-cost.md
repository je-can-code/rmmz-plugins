# Slot Cost

## Description

Want to control how many slot points a skill consumes? By applying the appropriate tag to skills in the database, you
can fine-tune the cost of equipping each skill.

## TAG USAGE

- Skills

## TAG FORMAT

`<slotCost:AMOUNT>`
Where AMOUNT is the number of slot points this skill costs to equip.

## TAG EXAMPLES

`<slotCost:2>`
This skill costs 2 slot points to equip into a slot.
