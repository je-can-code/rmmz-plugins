# Dependencies

All the various dependencies along with why they are dependencies live here.

## J-Base

All plugins in this ecosystem require the base plugin.

## J-Classes

Supplies the class scene whose parameters window the growth section is listed beneath, the copy of an actor in a class
its formulas are worked out for, and the multiplier measure this extends for parameters without a curve.

## J-NaturalGrowth

Supplies the Buff and Growth tags a class carries, the registry of which parameters answer to them, and the base their
formulas see as `b`.
