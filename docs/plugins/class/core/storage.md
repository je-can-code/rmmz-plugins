# Storage

This plugin will add the `_class` namespace to the actors to hold its class data.

## Parent

- All actors.

## Addition

The `_class` namespace.

## Save Section

`class`, when `J-Base-Save` is installed. Without it, the namespace saves inline with each actor in the normal save.
