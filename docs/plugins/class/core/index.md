# notetag

* [Unlockable For Actors](notetags/unlockable-for-actors.md) - The tag setting a class aside for particular actors, so only they can ever unlock it.

# plugin-parameter

* [Parameter Group: SETUP](parameters/parent-config.md) - The heading the SETUP parameters sit under in the plugin manager.
* [Menu Switch ID Plugin Parameter](parameters/menu-switch.md) - When this switch is ON, the class command is visible in the menu. Leave at 0 to always show it.
* [Menu Change Switch ID Plugin Parameter](parameters/menu-change-switch.md) - When this switch is ON, the menu's class command can change classes. Leave at 0 to only ever view.
* [Command Name Plugin Parameter](parameters/command-name.md) - The name of the class command in the menu.
* [Command Icon Plugin Parameter](parameters/command-icon.md) - The icon index of the class command in the menu.
* [Class Icon Plugin Parameter](parameters/class-icon.md) - The icon index drawn beside a class without an icon of its own, and beside every "???" class.

# plugin-command

* [Call Scene Plugin Command](commands/call-scene.md) - Opens the class scene for the party, either to change classes or only to review them.
* [Unlock Classes Plugin Command](commands/unlock-classes.md) - Unlocks classes for an actor, making them selectable in the class scene. Repeating an unlock does nothing.

# scene

* [Classes Scene](scenes/classes.md) - The scene for reviewing an actor's classes and, where the game allows it, changing between them.
