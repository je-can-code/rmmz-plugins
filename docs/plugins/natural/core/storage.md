# Storage

This plugin will add the `_natural` namespace to every actor to hold the natural buffs and growths it carries.

## Parent

All actors.

## Addition

The `_natural` namespace.

## Save Section

`natural`, when `J-Base-Save` is installed. Without it, the namespace saves inline with each actor in the normal save.
