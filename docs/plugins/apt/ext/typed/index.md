# notetag

* [Typed Teachable](notetags/typed-teachable.md) - The tag describing how much typed AP a skill costs to learn from a given source.
* [Typed AP Gain](notetags/typed-ap-gain.md) - The tag defining how many points of a particular type of AP an enemy yields upon defeat.

# plugin-parameter

* [Parameter Group: IMPLICIT SETUP](parameters/implicit-config.md) - The heading the IMPLICIT SETUP parameters sit under in the plugin manager.
* [Percent of Implicitly-Typed AP Gained Plugin Parameter](parameters/implicit-enemy-element-percent.md) - The percent of AP that will be gained from implicitly typed actions. Set to zero to disable implicit gains.
* [Elemental Alignment Threshold Plugin Parameter](parameters/resist-threshold.md) - The highest elemental rate allowed to identify an enemy's elemental alignment.
* [Slayer Alignment Threshold Plugin Parameter](parameters/slayer-weakness-threshold.md) - The lowest elemental rate allowed to identify an enemy's taxonomy alignment.
* [Excluded Alignment Elements Plugin Parameter](parameters/excluded-alignment-elements.md) - A list of elemental types that will not be considered for alignment.

# plugin-command

* [Add/Remove Typed AP (Party) Plugin Command](commands/mod-ap-all.md) - Adds or removes a designated amount of typed AP from all members of the current party.
* [Add/Remove Typed AP Plugin Command](commands/mod-ap.md) - Adds or removes a designated amount of typed AP from an actor by its id.
