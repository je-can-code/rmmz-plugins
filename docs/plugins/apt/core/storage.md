# Storage

This plugin will add the `_aptitude` namespace to every actor to store persisted teachables that the actor has earned
some number of AP for.

## Parent

All actors.

## Addition

The `_aptitude` namespace.

## Save Section

`aptitude`, when `J-Base-Save` is installed. Without it, the namespace saves inline with each actor in the normal save.
