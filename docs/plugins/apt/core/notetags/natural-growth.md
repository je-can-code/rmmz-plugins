# Natural Growth

This plugin integrates with `J-NaturalGrowth` to support the `apr` parameter.

See `J-NaturalGrowth` for details on how Buff/Growth and Plus/Rate behave.

## TAG FORMAT

`<aprBuffPlus:[FORMULA]>`
`<aprBuffRate:[FORMULA]>`
`<aprGrowthPlus:[FORMULA]>`
`<aprGrowthRate:[FORMULA]>`

## TAG EXAMPLES

`<aprGrowthPlus:[2]>`
The actor will gain +2% APR per level.
