# Subdirectories

* [J-ABS](abs/index.md) - Enables combat to be carried out on the map.
* [J-Aptitude](apt/index.md) - A plugin that grants the ability to learn by gaining points.
* [J-Base](_base/index.md) - The base class for all J plugins.
* [J-CA-Mods](__ca-mods/index.md) - JS Mods exclusive to Chef Adventure.
* [J-Classes](class/index.md) - Unlockable classes, and a scene to review and change them.
* [J-CMS](cms/index.md) - A redesign of the main menu.
* [J-CriticalFactors](crit/index.md) - Manages critical damage multiplier/reduction of battlers.
* [J-DropsControl](drops/index.md) - Enables greater control over loot drops.
* [J-Elementalistics](elem/index.md) - Enables greater control over elements.
* [J-Escriptions](escribe/index.md) - Enables "describing" the event with some text and/or an icon.
* [J-Extend](extend/index.md) - Extends the capabilities of skills/actions.
* [J-HUD](hud/index.md) - Provides core functionality for this HUD system.
* [J-JAFTING](jafting/index.md) - Root JAFTING menu, salvage loop, and extension hooks.
* [J-LevelMaster](level/index.md) - Allows levels to have greater control and purpose.
* [J-Lighting](lighting/index.md) - Declarative darkness and light sources for the map.
* [J-Log](log/index.md) - A log window for viewing on the map.
* [J-Map](map/index.md) - Renders a passability-driven minimap on the screen.
* [J-Message](message/index.md) - Gives access to more message window functionality.
* [J-Motion](motion/index.md) - Ambient and reactive motion for character sprites.
* [J-NaturalGrowth](natural/index.md) - Enables level-based growth of all parameters.
* [J-Omnipedia](omni/index.md) - Enables the "omnipedia" data-centric scene.
* [J-Passive](passive/index.md) - Grants passive states from various database objects.
* [J-Pixelistics](pixel/index.md) - Enables sub-tile (pixel-accurate) movement on the map.
* [J-Popups](popups/index.md) - Map text popups for JABS and beyond.
* [J-Proficiency](prof/index.md) - Enables skill proficiency tracking.
* [J-RegionEffects](regions/index.md) - A plugin that controls passage by region ids.
* [J-Resources](resources/index.md) - Extends skill cost/gain system to include HP, MP, and TP.
* [J-SDP](sdp/index.md) - Enables the SDP system, aka Stat Distribution Panels.
* [J-SkillSlots](sks/index.md) - A plugin enabling actors to equip skills into dedicated skill slots.
* [J-SystemUtilities](utils/index.md) - Various system utilities.
* [J-TIME](time/index.md) - A system for tracking time- real or artificial.
* [J-Weather](weather/index.md) - Named ambience and weather, declared per map.
