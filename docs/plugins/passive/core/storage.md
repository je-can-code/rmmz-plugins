# Storage

This plugin will add the `_passive` namespace to the actors and the party to hold its passive state data.

## Parent

- All actors.
- The party.

## Addition

The `_passive` namespace.

## Save Section

`passive`, when `J-Base-Save` is installed. Without it, the namespace saves inline with each parent in the normal save.
