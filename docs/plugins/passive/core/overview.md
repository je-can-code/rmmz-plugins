# Overview

This plugin enables the ability to have a various database objects provide passive effects in the form of states.

## Details

All database objects with notes can now provide the effects of a state within a given scope (usually just a single
battler, but in some cases the whole party) to the target by having or equipping said objects. Passive states are simply
states that are perpetually in effect while the condition is met, that condition varying depending on the tag.
