# Hide From Passives List

## Description

Stack amplifiers and other implementation-only passive duplicates can stay out of the
[Passives menu](../scenes/passive.md) while still contributing traits in combat.

## TAG USAGE

- States

## TAG FORMAT

`<hideFromPassiveList>`

## TAG EXAMPLES

`<hideFromPassiveList>`
