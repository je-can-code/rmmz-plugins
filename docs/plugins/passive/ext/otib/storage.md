# Storage

This plugin will add the `_otib` namespace to the actors to hold the one-time item boosts each actor has unlocked.

## Parent

- All actors.

## Addition

The `_otib` namespace.

## Save Section

`otib`, when `J-Base-Save` is installed. Without it, the namespace saves inline with each parent in the normal save.
