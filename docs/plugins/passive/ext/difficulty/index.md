# plugin-command

* [Call Difficulty Menu Plugin Command](commands/call-difficulty-menu.md) - Calls the difficulty menu regardless of the current scene.
* [Lock Difficulty Plugin Command](commands/lock-difficulty.md) - Locks a difficulty, making it unchoosable in the difficulty menu.
* [Unlock Difficulty Plugin Command](commands/unlock-difficulty.md) - Unlocks a difficulty, making it choosable in the difficulty menu.
* [Hide Difficulty Plugin Command](commands/hide-difficulty.md) - Hides a difficulty, preventing it from being added to the list in the difficulty menu.
* [Unhide Difficulty Plugin Command](commands/unhide-difficulty.md) - Shows a difficulty, forcing it to be added to the list in the difficulty menu.
* [Enable Difficulty Plugin Command](commands/enable-difficulty.md) - Enables a difficulty, applying its effects.
* [Disable Difficulty Plugin Command](commands/disable-difficulty.md) - Disables a difficulty, rendering its effects inactive.
* [Modify Layer Max Plugin Command](commands/modify-layer-max.md) - Modifies the maximum difficulty layer points by the given amount.
