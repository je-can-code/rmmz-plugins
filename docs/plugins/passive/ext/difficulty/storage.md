# Storage

This plugin will add the `_difficulty` namespace to the system to hold its difficulty data.

## Parent

- The system.

## Addition

The `_difficulty` namespace.

## Save Section

`difficulty`, when `J-Base-Save` is installed. Without it, the namespace saves inline with the system in the normal
save.
