# Blocking Random Affixes

## Description

Have you ever wanted a specific enemy to opt-out of random affixes entirely, or to only ever roll one slot? Well now you
can! By applying the following tags to an enemy note, you too can block random affix rolls per enemy.

## TAG USAGE

- Enemies

## TAG FORMAT

`<no-rng-passives>`
`<no-rng-passive-prefixes>`
`<no-rng-passive-suffixes>`

## TAG EXAMPLES

`<no-rng-passives>`
Prevents rolling both prefixes and suffixes for this enemy.

`<no-rng-passive-prefixes>`
Prevents rolling prefixes for this enemy, but suffixes may still roll.
