# Affix Pools

## Description

Have you ever wanted some passive states to act like "affix words", where a state can be eligible to become a prefix or
suffix? Well now you can! By applying the following tags to states, you too can define the pools this plugin rolls from.

## TAG USAGE

- States

## TAG FORMAT

`<enemy-prefix>`
`<enemy-suffix>`

## TAG EXAMPLES

`<enemy-prefix>`
This state can be selected as a prefix affix state.
