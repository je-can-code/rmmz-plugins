# notetag

* [Blocking Random Affixes](notetags/blocking-random-affixes.md) - The tags opting an enemy out of random prefix and suffix rolls, either both slots or just one.
* [Overriding Random Affix Chances](notetags/overriding-random-affix-chances.md) - The tags overriding the percent chance a prefix or suffix rolls, for one enemy or for one spawn point.
* [Affix Pools](notetags/affix-pools.md) - The tags making a state eligible to be rolled as an enemy's prefix or as its suffix.
* [Weighting Affix Rolls](notetags/weighting-affix-rolls.md) - The tag setting how often a state is drawn from its prefix or suffix pool, as a share of that pool.
* [Tier Stripe / Tint](notetags/tier-stripe-tint.md) - The tag setting the color a prefix state tints its map nameplate stripe, and optionally its HUD name row.
* [Tier Rank (Pip Count)](notetags/tier-rank-pip-count.md) - The tag ranking a prefix state's tier, drawn as that many thin pips on the map nameplate stripe.
* [Reward Multipliers](notetags/reward-multipliers.md) - The tag multiplying one kind of reward an enemy yields on defeat, set on the enemy or on its states.

# plugin-parameter

* [Parameter Group: PASSIVE AFFIX](parameters/parent-config-passive-affix.md) - The heading the PASSIVE AFFIX parameters sit under in the plugin manager.
* [Default Prefix Affix Chance Plugin Parameter](parameters/default-prefix-chance.md) - Percent chance to roll a random prefix affix when the slot is not blocked and no override applies.
* [Default Suffix Affix Chance Plugin Parameter](parameters/default-suffix-chance.md) - Percent chance to roll a random suffix affix when the slot is not blocked and no override applies.
* [Random Affix Switch Plugin Parameter](parameters/rng-enabled-switch.md) - The switch that must be ON for random affixes to roll. Set to 0 to always roll. Authored affixes ignore this.
