# Changelog

All the versioning and history of changes live here.

## The Actual Changelog

### 1.0.2
  - A targeted skill's hit pulse draws through J-ABS's hitbox painter, so it takes the hit's true shape, inner ring
    included, aimed the same way the hit is.
### 1.0.1
  - Relocating an action now copies its options through JABS_ActionOptions.withLocation rather than rebuilding every
    field by hand, so an option added later cannot be silently dropped on the way.
### 1.0.0
  - The initial release.
