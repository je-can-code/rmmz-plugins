# Food Chain Bar Color

## Description

Tag any phase state in a food chain arc with a hex color to control how its segment renders in the food chain HUD bar.

A phase state with no color tag renders as a neutral grey segment instead.

## TAG USAGE

- States

## TAG FORMAT

`<foodGroupColor:#RRGGBB>`
Where #RRGGBB is a six-digit hex color string.

## TAG EXAMPLES

`<foodGroupColor:#44cc44>`
This phase state's segment renders in the color #44cc44.
