# Food Items

## Description

Tag any item with `<food:TYPE>` to designate it as a food item. Food items are routed to the R2 food slot and excluded
from the tool slot.

## TAG USAGE

- Items

## TAG FORMAT

`<food:TYPE>`
Where TYPE is the lowercase chain group key (e.g. protein, vegetable, fruit).

## TAG EXAMPLES

`<food:protein>`
This item is a food item of the protein chain group.
