# Overview

This plugin enables the ability to display danger indicators on enemies while on the map.

This plugin requires [JABS](../../core/overview.md). This plugin is plug-n-play, with minimal configuration.

## Usage

If you are using JABS, then JABS already knows what to do to make use of this functionality. Just add this plugin
after/below JABS, and it'll work with no additional adjustments.
