# Subdirectories

* [J-ABS-AllyAI](allyai/index.md) - Grants your allies AI to fight alongside the player.
* [J-ABS-Boss](boss/index.md) - Data-driven boss encounters for J-ABS.
* [J-ABS-Charge](charge/index.md) - Enable skills to be charged to perform other skills.
* [J-ABS-DangerIndicator](danger/index.md) - Enable danger indicators on foes on the map.
* [J-ABS-Diagonals](diag/index.md) - Enables diagonal movement.
* [J-ABS-Dps](dps/index.md) - Measures how much damage each party member is dealing, and how fast.
* [J-ABS-Food](food/index.md) - A JABS extension enabling food group chain states and a dedicated R2 food slot.
* [J-ABS-Formula](formula/index.md) - An extension for JABS that allows multiple damage formulas.
* [J-ABS-Hitstop](hitstop/index.md) - An extension for JABS that adds hitstop functionality.
* [J-ABS-InputManager](input/index.md) - A manager for overseeing the input of JABS.
* [J-ABS-Juice](juice/index.md) - Procedural map battler motion juice for JABS (squish, tilt, casting pulse, weapon swing).
* [J-ABS-Loadout](loadout/index.md) - A scene for managing every party member's combat loadout.
* [J-ABS-Metrics](metrics/index.md) - Records JABS combat activity into game variables.
* [J-ABS-Poses](poses/index.md) - Enable action poses for JABS.
* [J-ABS-Shield](shield/index.md) - A JABS extension that provides state-based HP shields.
* [J-ABS-Speed](speed/index.md) - Enable modifying move speeds.
* [J-ABS-Targeting](targeting/index.md) - An extension for JABS that adds cursor-driven tactical targeting.
* [J-ABS-Time](time/index.md) - Calendar-based respawn methods for JABS.
* [J-ABS-Timing](timing/index.md) - Enable modifying cooldowns/casting for actions.
* [J-ABS-Tools](tools/index.md) - Enable new tool-like tags for use with skills.
