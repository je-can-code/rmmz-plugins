# No Juice

## Description

Suppresses all juice motion on the caster when this skill executes.

Equivalent to [`<juiceMotion:none>`](juice-motion.md).

## TAG USAGE

- Skills

## TAG FORMAT

`<noJuice>`

## TAG EXAMPLES

`<noJuice>`
