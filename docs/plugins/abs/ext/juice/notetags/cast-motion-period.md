# Cast Motion Period

## Description

Frames per repetition of the cast motion (default 8, which is about seven squats a second). Smaller is faster. Only
read when [`<castMotion:NAME>`](cast-motion.md) is set.

## TAG USAGE

- Skills

## TAG FORMAT

`<castMotionPeriod:N>`
Where N is the number of frames per repetition of the cast motion.

## TAG EXAMPLES

`<castMotionPeriod:6>`
One squat every six frames, ten a second.
