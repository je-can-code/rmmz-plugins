# Juice Stab Tip Degrees

## Description

Degrees from Pixi +x to bore/tip at rotation 0. Stab defaults to sword diagonal; bash / recoil default to barrel toward
−x unless overridden. Accepts negative values.

## TAG USAGE

- Skills

## TAG FORMAT

`<juiceStabTipDegrees:N>`
Where N is the degrees from Pixi +x to the icon's bore/tip at rotation 0.

## TAG EXAMPLES

`<juiceStabTipDegrees:-45>`
This skill's icon has its bore/tip at -45 degrees from Pixi +x at rotation 0.
