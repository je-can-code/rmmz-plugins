# Juice Span

## Description

Arc span in degrees for `arc` / `arc-reverse` / `arc-oscillate` (default 120; typical range 30–300).

## TAG USAGE

- Skills

## TAG FORMAT

`<juiceSpan:N>`
Where N is the arc span in degrees.

## TAG EXAMPLES

`<juiceSpan:150>`
This skill's arc spans 150 degrees.
