# Juice Profile Gun

## Description

Side-profile firearm icon: mirror east/west instead of ~180° rotation (keeps the grip from reading upside-down when the
art points left). Up/down still use ±90° rotation — pure side-view art cannot read as true top-down aim; use a separate
sprite or tune [degrees](juice-stab-tip-degrees.md).
