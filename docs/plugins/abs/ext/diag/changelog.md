# Changelog

All the versioning and history of changes live here.

## The Actual Changelog

### 1.1.3
  - Removed obsolete J.ABS.EXT.CYCLE / CycloneMovement guards from the moveStraight and moveDiagonally overrides;
    diagonal logic now runs unconditionally since Cyclone Movement is no longer supported.
### 1.1.2
  - Raised minimum J-ABS version requirement to 4.7.0.
### 1.1.1
  - Raised minimum J-ABS version requirement to 4.6.0.
### 1.1.0
  - Retroactively added this CHANGELOG.
  - Removed unnecessary references to Cyclone-Movement from this plugin.
  - Cleaned up the code and added jsdocs.
  - Updated the plugin help to have a more verbose explanation.
### 1.0.0
  - The initial release.
