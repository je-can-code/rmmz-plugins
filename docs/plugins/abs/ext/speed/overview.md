# Overview

This plugin enables modifications of movespeed for characters on the map.

This plugin requires [JABS](../../core/overview.md). This plugin requires no plugin parameter configuration.

## Details

The new parameter of ["movement speed boost"](notetags/movement-speed-boost.md) is a calculated parameter that gets
cached when things change on battlers.
