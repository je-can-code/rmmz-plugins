# Hiding Items/Skills From Assignment

## Description

To prevent certain items or skills from appearing in the [assignment menu](../scenes/jabs-loadout.md) for a given slot.

This applies to "dodge" and "combat" skills and "tools". Hidden skills still appear in the main menu.

## TAG USAGE

- Skills, for "dodge" and "combat" skills.
- Items, for "tools".

## TAG FORMAT

`<hideFromJabsMenu>`

## TAG EXAMPLES

`<hideFromJabsMenu>`
This item or skill does not appear in the assignment menu for its slot.
