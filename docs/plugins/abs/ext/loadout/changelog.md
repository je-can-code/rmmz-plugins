# Changelog

## The Actual Changelog

### 1.1.0
  - An item authored for the battle screen is now eligible for a combat slot alongside an always-usable one. In an ABS
    the map is the battle, so battle-only is the strongest claim an item can make to belonging in a slot, not a weaker
    one.
  - Menu-only and never remain excluded.
