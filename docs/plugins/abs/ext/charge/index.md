# plugin-parameter

* [Parameter Group: DEFAULTS](parameters/defaults.md) - The heading the DEFAULTS parameters sit under in the plugin manager.
* [Charging Animation Plugin Parameter](parameters/default-charging-anim-id.md) - This will be the default animation to play when a while charging up. 0 means no animation.
* [Tier Complete Animation Plugin Parameter](parameters/default-tier-complete-anim-id.md) - This will be the default animation to play when a charging tier is charged. 0 means no animation.
* [Fully Charged Animation Plugin Parameter](parameters/default-fully-charged-anim-id.md) - This will be the default animation to play when the player can charge no further- aka the final tier completed.
* [Charge Tier Complete SE Plugin Parameter](parameters/tier-complete-se.md) - This will be the default sound effect to play when a charging tier is charged. Empty means no sound effect.
* [Max Charge Ready SE Plugin Parameter](parameters/charge-ready-se.md) - This will be the default sound effect to play when a all tiers are charged and ready. Empty means no sound effect.
* [Use Tier Complete SE Plugin Parameter](parameters/use-default-charging-se.md) - Whether or not to use the tierComplete and chargeReady sound effects.
* [Allow Tier Complete SE/Anim Plugin Parameter](parameters/allow-tier-complete-s-eand-anim.md) - Whether or not to use both sound effects and the defined animations when a charging tier completes.
