* [Parameter Group: MENU DETAILS](parameters/menu-configs.md) - The heading the MENU DETAILS parameters sit under in the plugin manager.

* [Parameter Group: ALLY FORMATIONS DETAILS](parameters/ally-formations-configs.md) - The heading the ALLY FORMATIONS DETAILS parameters sit under in the plugin manager.
* [Formations Command Text Plugin Parameter](parameters/ally-formations-command-name.md) - The text displayed for the ally formations command in the party menu.
* [Formations Command Icon Plugin Parameter](parameters/ally-formations-command-icon-index.md) - The icon displayed beside the ally formations command.
* [Parameter Group: AI-MODE DETAILS](parameters/ai-mode-configs.md) - The heading the AI-MODE DETAILS parameters sit under in the plugin manager.
* [Mode Equipped Icon Plugin Parameter](parameters/ai-mode-equipped.md) - The icon indicating that the mode is equipped.
* [Mode Not Equipped Icon Plugin Parameter](parameters/ai-mode-not-equipped.md) - The icon indicating that the mode is not equipped.
