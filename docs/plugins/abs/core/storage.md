# Storage

This plugin will add the `_abs` namespace to the actors, the party, the system, and the characters on the map to hold
its combat data.

## Parent

- All actors.
- The party.
- The system.
- The characters on the map: the player, followers and events.

## Addition

The `_abs` namespace.

## Save Section

`abs`, when `J-Base-Save` is installed. Without it, the namespace saves inline with each parent in the normal save.
