# No Switch

## Description

Prevents the player from switching to this actor as the party leader via the JABS party rotate command. Use this for
actors that should never be player-controlled (permanent support members, story actors, etc.).

## TAG USAGE

- Actors
- Classes

## TAG FORMAT

`<noSwitch>`

## TAG EXAMPLES

`<noSwitch>`
The player cannot switch to this actor as the party leader.
