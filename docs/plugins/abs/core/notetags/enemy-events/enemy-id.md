# Enemy ID

## Description

If you want an event to act as an enemy, the system needs a way to associate the event with the enemy in the database.
Use the "enemy" tag.

## TAG USAGE

- Event comments, on an enemy event.

## TAG FORMAT

`<enemyId:ENEMY_ID>`
Where ENEMY_ID is the id from the database for this enemy.

## TAG EXAMPLES

`<enemyId:5>`
This event acts as the enemy with id 5 from the database.
