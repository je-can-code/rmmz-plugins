# Cast Time

## Description

The number of frames the battler must wait before the skill fires. While casting, the "cast animation" will loop if one
is defined.

## TAG USAGE

- Skills

## TAG FORMAT

`<castTime:VAL>`
Where VAL is the number of frames to cast this skill.

## TAG EXAMPLES

`<castTime:60>`
This skill takes 60 frames to cast.
