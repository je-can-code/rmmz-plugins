# Self Animation

## Description

An animation that plays on the caster when the skill hits a target.

## TAG USAGE

- Skills

## TAG FORMAT

`<selfAnimationId:VAL>`
Where VAL is the animation id to execute once the hit lands.

## TAG EXAMPLES

`<selfAnimationId:45>`
The animation of id 45 plays on the caster once the hit lands.
