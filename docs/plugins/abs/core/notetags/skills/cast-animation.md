# Cast Animation

## Description

An animation that loops on the caster while the skill is being cast.

## TAG USAGE

- Skills

## TAG FORMAT

`<castAnimation:VAL>`
Where VAL is the animation id to loop while casting.

## TAG EXAMPLES

`<castAnimation:12>`
The animation of id 12 loops on the caster while casting.
