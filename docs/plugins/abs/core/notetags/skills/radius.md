# Radius

## Description

How large the hitbox of this skill is, using tiles as measurement. Must be a positive number.

## TAG USAGE

- Skills

## TAG FORMAT

`<radius:VAL>`
Where VAL is the radius value for this skill.

## TAG EXAMPLES

`<radius:2>`
This skill's hitbox has a radius of 2 tiles.
