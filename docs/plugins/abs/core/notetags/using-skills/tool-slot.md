# Tool Slot

## Description

The tool slot is always player-assigned and represents usable items. Like equipment, assign a SKILL_ID to them to make
them usable.

## TAG USAGE

- Items

## TAG FORMAT

`<skillId:SKILL_ID>`
Where SKILL_ID is the skill to perform from the tool slot.

## TAG EXAMPLES

`<skillId:30>`
This item performs skill 30 from the tool slot.
