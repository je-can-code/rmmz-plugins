# Dodge Distance

## TAG USAGE

- Skills, of the dodge skill type.

## TAG FORMAT

`<dodge:DISTANCE>`
Where DISTANCE is the number of tiles to be forcefully moved.

## TAG EXAMPLES

`<dodge:3>`
This dodge forcefully moves the player 3 tiles.
