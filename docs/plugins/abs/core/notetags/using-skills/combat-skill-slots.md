# Combat Skill Slots

## Description

There are four combat skill slots, all player-assigned. They can be swapped at any time from the quickmenu using skills
the player knows and has set up with the appropriate tags.

## TAG USAGE

- Skills, ones the player knows; the slots themselves take no tag.

## TAG FORMAT

There is no tag for these slots. The player assigns known skills to them from the quickmenu.
