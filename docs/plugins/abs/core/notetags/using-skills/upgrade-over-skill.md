# Upgrade Over Skill

## Description

Makes a newly learned skill replace a currently equipped skill.

## NOTE ABOUT UNEQUIPPED TARGETS

If the target skill isn't equipped, the new skill will still be auto-assigned unless it has a tag preventing it.

## TAG USAGE

- Skills, on the newly learned skill.

## TAG FORMAT

`<upgradeOverSkill:NUM>`
Where NUM is the skill id this skill should replace.

## TAG EXAMPLES

`<upgradeOverSkill:10>`
Once learned, this skill replaces skill 10 where it is currently equipped.
