# Dodge Speed

## TAG USAGE

- Skills, of the dodge skill type.

## TAG FORMAT

`<dodgeSpeed:MODIFIER>`
Where MODIFIER is added to the player's current move speed.
Note that this value can be a decimal or negative.

## TAG EXAMPLES

`<dodgeSpeed:1.5>`
This dodge adds 1.5 to the player's current move speed.
