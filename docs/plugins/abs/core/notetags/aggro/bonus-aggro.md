# Bonus Aggro

## NOTE ABOUT HIT/MISS/PARRY

All aggro tags fire regardless of hit/miss/parry, same as the base aggro calculation chain.

## TAG USAGE

- Skills

## TAG FORMAT

`<aggro:VAL>`
Where VAL is the flat amount of aggro to gain (or lose if negative).

## TAG EXAMPLES

`<aggro:50>`
The caster gains 50 flat aggro from this skill.
