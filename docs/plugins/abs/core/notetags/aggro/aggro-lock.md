# Aggro Lock

## Description

Prevents this battler's aggro from changing while the state is active. They can still affect others' aggro, but theirs
is frozen.

## TAG USAGE

- States

## TAG FORMAT

`<aggroLock>`

## TAG EXAMPLES

`<aggroLock>`
While this state is active, the battler's aggro is frozen.
