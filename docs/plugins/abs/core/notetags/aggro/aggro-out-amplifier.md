# Aggro Out Amplifier

## Description

Multiplies all aggro this battler generates while the state is active.

## TAG USAGE

- States

## TAG FORMAT

`<aggroOutAmp:VAL>`
Where VAL is the decimal multiplier against outgoing aggro.

## TAG EXAMPLES

`<aggroOutAmp:1.5>`
While this state is active, all aggro this battler generates is multiplied by 1.5.
