# Aggro In Amplifier

## Description

Multiplies all aggro received by this battler while the state is active.

## TAG USAGE

- States

## TAG FORMAT

`<aggroInAmp:VAL>`
Where VAL is the decimal multiplier against incoming aggro.

## TAG EXAMPLES

`<aggroInAmp:0.5>`
While this state is active, all aggro received by this battler is multiplied by 0.5.
