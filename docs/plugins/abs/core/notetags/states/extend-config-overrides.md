# Extend Config Overrides

## TAG USAGE

- States

## TAG FORMAT

`<stackExtendAmount:VAL>`
Frames added to the remaining duration on each extend application.

`<stackExtendMax:VAL>`
The maximum total duration this state can be extended to.

## TAG EXAMPLES

`<stackExtendAmount:120>`
120 frames are added to the remaining duration on each extend application.

`<stackExtendMax:1200>`
This state can be extended to a maximum total duration of 1200 frames.
