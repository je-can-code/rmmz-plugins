# Vis Rotate

## Description

Makes the action sprite rotate to face the direction it is moving. Useful for directional projectile sprites like
arrows or energy beams.

## TAG USAGE

- Skills

## TAG FORMAT

`<visRotate>`

## TAG EXAMPLES

`<visRotate>`
The action sprite rotates to face the direction it is moving.
