# Vis Scale

## Description

Overrides the scale (stretch) of the action sprite.

## TAG USAGE

- Skills

## TAG FORMAT

`<visScale:[SX,SY]>`
Where SX is the horizontal scale (1.0 = normal).
Where SY is the vertical scale (1.0 = normal).

## TAG EXAMPLES

`<visScale:[2.0,1.0]>`
The action sprite is twice its normal horizontal scale, at its normal vertical scale.
