# Vis Z

## Description

Overrides the z-order of the action sprite, controlling whether it renders above or below other map sprites.

## TAG USAGE

- Skills

## TAG FORMAT

`<visZ:VAL>`
Where VAL is the z-order integer (higher = renders on top).

## TAG EXAMPLES

`<visZ:5>`
The action sprite renders at z-order 5.
