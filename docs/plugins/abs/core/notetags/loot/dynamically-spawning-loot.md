# Dynamically Spawning Loot

## Description

Plugin/script commands can generate and spawn loot at any map location. See the plugin commands for input parameter
details.

## TAG USAGE

- Events, as a plugin command rather than a notetag.

## TAG FORMAT

`Spawn Loot`
The `J-ABS` plugin command, given the map coordinates and the items, weapons and armors to drop there.
