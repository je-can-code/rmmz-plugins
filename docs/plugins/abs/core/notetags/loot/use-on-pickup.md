# Use on Pickup

## Description

The "heart drop" from Zelda: an item that heals when picked up. Add this tag to any droppable item to have it
immediately perform as if used on the player who picks it up.

## TAG USAGE

- Items

## TAG FORMAT

`<useOnPickup>`

## TAG EXAMPLES

`<useOnPickup>`
This item immediately performs as if used on the player who picks it up.
