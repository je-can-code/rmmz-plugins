# Expiration

## Description

Override the default loot duration for a specific drop.

## NOTE ABOUT MAP TRANSFER

All loot is erased on map transfer. This is intentional.

## TAG USAGE

- Items
- Weapons
- Armor

## TAG FORMAT

`<expires:DURATION>`
Where DURATION is the number of frames the loot persists.

## TAG EXAMPLES

`<expires:600>`
This loot persists for 600 frames.
