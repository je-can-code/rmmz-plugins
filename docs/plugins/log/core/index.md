# plugin-command

* [Show Action Log Window Plugin Command](commands/show-action-log.md) - Turns the action log window visible to allow logs to be displayed.
* [Hide Action Log Window Plugin Command](commands/hide-action-log.md) - Turns the action log window invisible. Logs still get logged, but can't be seen.
* [Add Log Plugin Command](commands/add-action-log.md) - Arbitrarily create a log for the log window. Respects text codes.
* [Clear Action Logs Plugin Command](commands/clear-action-log.md) - Clears all the logs out of the action log.
* [Show DiaLog Window Plugin Command](commands/show-dia-log.md) - Turns the adialog window visible to allow logs to be displayed.
* [Hide DiaLog Window Plugin Command](commands/hide-dia-log.md) - Turns the dialog window invisible. Logs still get logged, but can't be seen.
* [Add DiaLog Plugin Command](commands/add-dia-log.md) - Adds a single DiaLog into the DiaLog Window. Respects text codes.
* [Clear DiaLog Plugin Command](commands/clear-dia-log.md) - Clears all the logs out of the dialog log.
* [Show Loot Log Window Plugin Command](commands/show-loot-log.md) - Turns the action log window visible to allow logs to be displayed.
* [Hide Loot Log Window Plugin Command](commands/hide-loot-log.md) - Turns the action log window invisible. Logs still get logged, but can't be seen.
* [Add Loot Log Plugin Command](commands/add-loot-log.md) - Arbitrarily create a log for the log window. Respects text codes.
* [Clear Loot Logs Plugin Command](commands/clear-loot-log.md) - Clears all the logs out of the action log.
