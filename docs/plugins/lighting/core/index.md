# notetag

* [Ambient Darkness](notetags/ambient-darkness.md) - The tag declaring how much light a map has lost, and what colour the dark it leaves behind is.
* [Light Source](notetags/light-source.md) - The tag declaring a source of light, with a reach in tiles and an optional colour, edge and effect.

# plugin-command

* [Apply Darkness Plugin Command](commands/apply-ambient.md) - Darkens the scene until removed. Compounds with the map's own darkness rather than replacing it.
* [Remove Darkness Plugin Command](commands/remove-ambient.md) - Withdraws darkness applied by plugin command. The map's own darkness is untouched.
* [Lights On Plugin Command](commands/lights-on.md) - Turns the lights on somewhere the map itself calls dark. Lasts until the player next arrives here.
* [Lights Off Plugin Command](commands/lights-off.md) - Gives a place its own darkness back after Lights On.
