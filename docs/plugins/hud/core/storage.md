# Storage

This plugin will add the `_hud` namespace to the system to hold its HUD data.

## Parent

The system.

## Addition

The `_hud` namespace.

## Save Section

`hud`, when `J-Base-Save` is installed. Without it, the namespace saves inline with the system in the normal save.
