# Subdirectories

* [J-HUD-BossFrame](boss/index.md) - A HUD frame that displays a single target, like a boss.
* [J-HUD-Dps](dps/index.md) - A J-HUD extension that displays each battle member's damage output.
* [J-HUD-Food](food/index.md) - A J-HUD extension that displays the current food chain status on screen.
* [J-HUD-InputFrame](input/index.md) - A HUD frame that displays your leader's buttons data.
* [J-HUD-PartyFrame](party/index.md) - A HUD frame that displays your party's data.
* [J-HUD-QuestFrame](quest/index.md) - A HUD frame that displays quest objective information.
* [J-HUD-TargetFrame](target/index.md) - A HUD frame that displays your battle target.
