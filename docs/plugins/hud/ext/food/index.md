# plugin-parameter

* [Window X Plugin Parameter](parameters/window-x.md) - The x coordinate of the food chain window's top-left corner.
* [Window Y Plugin Parameter](parameters/window-y.md) - The y coordinate of the food chain window's top-left corner.
* [Window Width Plugin Parameter](parameters/window-width.md) - Width of the food chain strip. Widen if long state names (e.g. Well Fed (protein)) clip horizontally.
* [Window Height Plugin Parameter](parameters/window-height.md) - Total window height. Only grows the chain-state label list; icon and bar size stay fixed. Every chain phase is drawn at full row height — raise this if a longer chain clips.
* [Window Opacity Plugin Parameter](parameters/window-opacity.md) - Opacity of the windowskin frame and backdrop only (0 = invisible panel, 255 = opaque). Food icons, bar, and labels stay fully visible.
