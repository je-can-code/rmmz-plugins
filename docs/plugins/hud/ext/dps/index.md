# plugin-parameter

* [Show Readout Plugin Parameter](parameters/enabled.md) - Whether or not the damage readout is drawn. Off by default; this is an instrument rather than part of the game.
* [Window X Plugin Parameter](parameters/window-x.md) - The x coordinate of the readout's top-left corner.
* [Window Y Plugin Parameter](parameters/window-y.md) - The y coordinate of the readout's top-left corner.
* [Window Width Plugin Parameter](parameters/window-width.md) - Width of the readout. Widen if long battler names clip in the leading column.
* [Window Height Plugin Parameter](parameters/window-height.md) - Height of the readout. Needs one row for the headings plus one per battle member; raise it if rows clip.
* [Window Opacity Plugin Parameter](parameters/window-opacity.md) - Opacity of the windowskin frame and backdrop only (0 = invisible panel, 255 = opaque). The numbers stay fully visible.
