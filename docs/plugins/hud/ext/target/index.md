# plugin-parameter

* [Parameter Group: Target Frame Window](parameters/target-frame-data.md) - The heading the Target Frame Window parameters sit under in the plugin manager.
* [Origin X Plugin Parameter](parameters/target-frame-x.md) - The x coordinate of the overarching target frame.
* [Origin Y Plugin Parameter](parameters/target-frame-y.md) - The y coordinate of the overarching target frame.
* [Width Plugin Parameter](parameters/target-frame-width.md) - The width in pixels of the target frame window.
* [Height Plugin Parameter](parameters/target-frame-height.md) - The height in pixels of the target frame window.
* [Parameter Group: Target Settings](parameters/settings.md) - The heading the Target Settings parameters sit under in the plugin manager.
* [For HP: Plugin Parameter](parameters/hp-settings.md) - The For HP: plugin parameter.
* [Use Gauge Plugin Parameter](parameters/enable-hp.md) - Enables the HP gauge in the target frame.
* [For MP: Plugin Parameter](parameters/mp-settings.md) - The For MP: plugin parameter.
* [Use Gauge Plugin Parameter](parameters/enable-mp.md) - Enables the MP gauge in the target frame.
* [For TP: Plugin Parameter](parameters/tp-settings.md) - The For TP: plugin parameter.
* [Use Gauge Plugin Parameter](parameters/enable-tp.md) - Enables the TP gauge in the target frame.
* [Rotation Plugin Parameter](parameters/tp-gauge-rotation.md) - The degree of rotation for the TP gauge. Between -360 and 360.
