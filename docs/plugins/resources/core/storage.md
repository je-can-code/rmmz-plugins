# Storage

This plugin will add the `_resources` namespace to every battler.

## Parent

- All battlers, actors and enemies alike. Only actors are written to a save.

## Addition

The `_resources` namespace.

## Save Section

`resources`, when `J-Base-Save` is installed. Without it, the namespace saves inline with each parent in the normal
save.
