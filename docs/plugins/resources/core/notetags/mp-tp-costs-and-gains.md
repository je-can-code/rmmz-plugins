# Extra MP and TP Costs and Gains

## Description

Have you ever wanted more expressive MP and TP costs than the single integer the editor provides? Well now you can! The
same flat/percent/formula tag system is available for MP and TP, layered on top of the editor's native cost fields so
you don't lose anything you've already set up.

## TAG USAGE

- Skills

## TAG FORMAT

`<mp-cost:VALUE>`
`<mp-cost:PERCENT%>`
`<mp-cost:[FORMULA]>`

`<tp-cost:VALUE>`
`<tp-cost:PERCENT%>`
`<tp-cost:[FORMULA]>`

`<mp-gain:VALUE>`
`<mp-gain:PERCENT%>`
`<mp-gain:[FORMULA]>`

`<tp-gain:VALUE>`
`<tp-gain:PERCENT%>`
`<tp-gain:[FORMULA]>`

## TAG EXAMPLES

`<mp-cost:10>`
An MP cost layered on top of the editor's native cost fields.
