# HP Gain

## Description

Have you ever wanted a skill that restores HP to the caster upon use, separate from damage formulas? Well now you can!
By applying the appropriate tag(s) to a skill, the caster will recover HP when the skill is executed.

## TAG USAGE

- Skills

## TAG FORMAT

`<hp-gain:FLAT>`

`<hp-gain:PERCENT%>`

`<hp-gain:[FORMULA]>`

## TAG EXAMPLES

`<hp-gain:50>`
The caster will recover HP when the skill is executed.
