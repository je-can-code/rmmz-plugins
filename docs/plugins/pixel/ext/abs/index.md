# notetag

* [Hitbox Size](notetags/hitbox-size.md) - The tag giving an enemy battler a rectangular, feet-anchored hitbox of a given width and height in tiles.
* [Hitbox Reveal](notetags/hitbox-reveal.md) - The tag setting how close the player must be for an enemy battler to reveal its hitbox outline.

# plugin-parameter

* [Parameter Group: IDLE MOVEMENT](parameters/idle-configs.md) - The heading the IDLE MOVEMENT parameters sit under in the plugin manager.
* [Idle Wander Radius Plugin Parameter](parameters/idle-wander-radius.md) - Distance in tiles from home an enemy may wander while idle. Default 1.5 gives a 3x3-tile area.
* [Parameter Group: ENEMY HITBOX](parameters/enemy-hitbox-configs.md) - The heading the ENEMY HITBOX parameters sit under in the plugin manager.
* [Default Enemy Hitbox Width Plugin Parameter](parameters/default-enemy-hitbox-width.md) - Full enemy hitbox width in tiles when no event or enemy override exists.
* [Default Enemy Hitbox Height Plugin Parameter](parameters/default-enemy-hitbox-height.md) - Full enemy hitbox height in tiles when no event or enemy override exists.
* [Outline Always Active Plugin Parameter](parameters/outline-always-active.md) - If true, all eligible battler hitbox outlines are always visible regardless of range.
* [Default Hitbox Reveal Range Plugin Parameter](parameters/default-hitbox-reveal-range.md) - Reveal hitbox outlines within this many tiles when no event or enemy override exists. 0 disables proximity mode.
