# notetag

* [Additional Elements](notetags/additional-elements.md) - The tag adding one or more extra attack elements to a skill.
* [Absorb Elements](notetags/absorb-elements.md) - The tag making a battler absorb one or more elements from anything that performs elemental calculations.
* [Boost Elements](notetags/boost-elements.md) - The tag boosting (or penalizing) the damage a battler deals with skills of a particular element.
* [Strict Elements](notetags/strict-elements.md) - The tag restricting the elements a battler can be hurt by to a whitelist.
* [Pierce Elements](notetags/pierce-elements.md) - The tags letting a battler partially ignore a target's elemental resistance, on all skills or on one skill.
