# SDP Points (Enemies Only)

## Description

Ever want enemies to drop SDP Points? Well now they can! By applying the appropriate tag to the enemy/enemies in
question, you can have enemies drop as little or as much as you want them to.

## TAG USAGE

- Enemies only.

## TAG FORMAT

`<sdp:POINTS>`

## TAG EXAMPLES

`<sdp:10>`
The party will gain 10 SDP points from defeating this enemy.

`<sdp:123456>`
The party will gain 123456 SDP points from defeating this enemy.
