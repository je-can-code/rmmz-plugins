# Natural Growth

## Description

With `J-NaturalGrowth` also installed, the SDP multiplier (`sdr`) accepts its buff and growth tags. Amounts are
percents, like `<sdpMultiplier:NUM>`.

See `J-NaturalGrowth` for how Buff/Growth and Plus/Rate behave.

## TAG USAGE

- See `J-NaturalGrowth`.

## TAG FORMAT

`<sdrBuffPlus:[FORMULA]>`
`<sdrBuffRate:[FORMULA]>`
`<sdrGrowthPlus:[FORMULA]>`
`<sdrGrowthRate:[FORMULA]>`

## TAG EXAMPLES

`<sdrGrowthPlus:[1]>`
Grants 1% more SDP points per level.
