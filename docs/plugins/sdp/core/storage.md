# Storage

This plugin will add the `_sdp` namespace to the actors, the party, and the system to hold its SDP data.

## Parent

- All actors.
- The party.
- The system.

## Addition

The `_sdp` namespace.

## Save Section

`sdp`, when `J-Base-Save` is installed. Without it, the namespace saves inline with each parent in the normal save.
