# Storage

This plugin will add the `_playthroughId` field to the system, to identify the playthrough a game belongs to.

## Parent

The system.

## Addition

The `_playthroughId` field.

## Save Section

None of its own. The field is written with the rest of the system, into each generation's `world.json`.
