# notetag

* [Max Item Quantity](notetags/max-item-quantity.md) - The tag defining the maximum quantity allowed for an item, weapon or armor.
* [Custom Max TP](notetags/custom-max-tp.md) - The tag defining how much max TP a database entry provides to the battler it belongs to.
* [State Type Classifier](notetags/state-type-classifier.md) - The tag grouping a state into one or more named categories that other plugins and tags can react to.
* [HAR (Healing Rate)](notetags/har-healing-rate.md) - The tag raising or lowering the potency of the healing a battler deals out, separately from REC.

# plugin-parameter

* [Actor Base TP Max Plugin Parameter](parameters/actor-base-tp.md) - The base TP for actors is this amount. Any formulai add onto this.
* [Enemy Base TP Max Plugin Parameter](parameters/enemy-base-tp.md) - The base TP for enemies is this amount. Any formulai add onto this.
* [New Game Common Event Plugin Parameter](parameters/new-game-common-event-id.md) - A common event executed once when a new game begins, before the first map runs anything of its own. 0 disables it.
