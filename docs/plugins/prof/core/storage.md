# Storage

This plugin will add the `_proficiency` namespace to every actor to hold its proficiency data.

## Parent

All actors.

## Addition

The `_proficiency` namespace.

## Save Section

`proficiency`, when `J-Base-Save` is installed. Without it, the namespace saves inline with each actor in the normal
save.
