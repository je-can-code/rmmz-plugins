# Natural Growth

## Description

With `J-NaturalGrowth` also installed, the proficiency bonus (`prof`) accepts its buff and growth tags, in the same flat
numbers as `<proficiencyBonus:NUM>`.

See [`J-NaturalGrowth`](../../../natural/core/notetags/natural-growth.md) for how Buff/Growth and Plus/Rate behave.

## TAG USAGE

- See `J-NaturalGrowth`.

## TAG FORMAT

`<prof(Buff|Growth)(Plus|Rate):[FORMULA]>`

## TAG EXAMPLES

`<profGrowthPlus:[1]>`
Grants +1 proficiency per use for every level gained.
