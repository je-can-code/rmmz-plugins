# plugin-parameter

* [Sync Indicator Icon Plugin Parameter](parameters/sync-indicator-icon.md) - Icon index shown beside level text while content sync is active. Set to 0 to suppress the icon.
* [Sync Affects EXP Plugin Parameter](parameters/sync-affects-exp.md) - If true, EXP rewards use the synced level. If false (default), real level governs EXP — preserving J-Level-Flat's design.

# plugin-command

* [Set Content Sync Plugin Command](commands/set-content-sync.md) - Activates content level sync at the specified level for all party members.
* [Clear Content Sync Plugin Command](commands/clear-content-sync.md) - Deactivates the active content sync session and restores real effective levels.
