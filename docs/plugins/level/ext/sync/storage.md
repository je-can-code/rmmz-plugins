# Storage

This plugin will add the `_levelSync` namespace to the system and the map to hold its content sync data.

## Parent

- The system.
- The map.

## Addition

The `_levelSync` namespace.

## Save Section

`level-sync`, when `J-Base-Save` is installed. Without it, the namespace saves inline with each parent in the normal
save.
