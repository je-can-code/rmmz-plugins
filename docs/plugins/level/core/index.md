# notetag

* [Level](notetags/level.md) - The tags giving an enemy a level, modifying a battler's level, and hiding an enemy's level from its name.
* [Skill Learning](notetags/skill-learning.md) - The tag holding one of an enemy's skills back until the enemy reaches a given level.
* [Max Level Boost](notetags/max-level-boost.md) - The tag raising or lowering an actor's max level, beyond the database's cap of 99.
* [Growth Curves](notetags/growth-curves.md) - The tags giving a class an authored formula for a parameter beyond level 99, and for its base max TP.

# plugin-command

* [Enable Scaling Plugin Command](commands/enable-scaling.md) - Enables the scaling functionality for damage/rewards.
* [Disable Scaling Plugin Command](commands/disable-scaling.md) - Disables the scaling functionality for damage/rewards.
