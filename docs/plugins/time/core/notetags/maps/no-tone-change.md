# No Tone Change

## Description

If you want the auto-tone changing, but want it disabled for certain maps, then you can use this note tag which will
cause the system to not change the tone when transfering to that particular map.

## TAG USAGE

- Maps, in the map's note field.

## TAG FORMAT

`<noToneChange>`

## TAG EXAMPLES

`<noToneChange>`
The system does not change the tone when transferring to this map.
