# No Weather

## Description

Opts a map out of weather entirely. Nothing falls here, whatever the sky is doing.

This is deliberately rare. An ordinary interior already draws nothing without being told, so it needs no tag at all.
This exists for the narrower case of somewhere that genuinely has sky overhead and still should not be rained on: a
covered market, a colonnade, a courtyard under a canopy.

It outranks everything, including a [`<weather:>`](map-weather.md) tag on the same map.

## TAG USAGE

- Maps, in the map's note box.

## TAG FORMAT

`<noWeather>`
