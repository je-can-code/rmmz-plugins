# Overview

This plugin is an extension of [`J-Extend`](../../core/overview.md) for [`J-ABS`](../../../abs/core/overview.md). It
prevents the JABS AI from selecting skill-extension skills as actions.

## Note about notetags

This plugin has no notetags of its own- it is pure integration glue between `J-Extend` and `J-ABS`'s AI
skill-selection logic.
