# notetag

* [Skill Extension](notetags/skill-extension.md) - The tag making a skill or state act as an extension to other skills or states, listed by id.
* [Extension By Type](notetags/extension-by-type.md) - The tag making a skill or state extend every skill or state that carries a matching type classifier.
* [State Reaction Effects](notetags/state-reaction-effects.md) - The tags making a skill apply, lose, strip or remove states, or force-execute skills, when cast or on hit.
* [On-Hit Apply State (Skill-Scoped)](notetags/on-hit-apply-state-skill-scoped.md) - The tag making one skill apply a state to its target on hit, with an authored chance, duration and stacks.
* [On-Hit Apply State (Caster-Wide)](notetags/on-hit-apply-state-caster-wide.md) - The tag making every hit a battler lands apply a state, with an authored chance, duration and stacks.
* [Toggle State On Execute](notetags/toggle-state-on-execute.md) - The tag making a skill flip a state on or off on its caster each time it executes, for stance skills.
* [Toggle State Group On Execute](notetags/toggle-state-group-on-execute.md) - The tag making a skill cycle its caster through a coupled group of states, one step per execution.
