# Slip Popup Suppression

## Description

The following notetags are supported by this plugin. They suppress the slip/regen popups that a state generates- per
resource (HP, MP, or TP), or all three at once.

## TAG USAGE

- States only.

## TAG FORMAT

`<noHpPopup>`
Suppresses HP slip/regen popups generated by this state.

`<noMpPopup>`
Suppresses MP slip/regen popups generated by this state.

`<noTpPopup>`
Suppresses TP slip/regen popups generated by this state.

`<noSlipPopup>`
Suppresses ALL slip/regen popups (HP, MP, and TP) generated by this state.

## TAG EXAMPLES

`<noHpPopup>`
This state's HP slip/regen ticks show no popups.
