# plugin-parameter

* [Parameter Group: BASE SETUP](parameters/bas-econfigs.md) - The heading the BASE SETUP parameters sit under in the plugin manager.
* [Minimap X Plugin Parameter](parameters/minimap-x.md) - X position of the minimap in screen pixels; -1 = auto bottom-right.
* [Minimap Y Plugin Parameter](parameters/minimap-y.md) - Y position of the minimap in screen pixels; -1 = auto bottom-right.
* [Start Visible Plugin Parameter](parameters/start-visible.md) - If true, the minimap starts visible on new game/load.
* [Respect JABS HUD Visibility Plugin Parameter](parameters/respect-hud-hide.md) - If true, the minimap hides when the HUD is hidden via input.
* [Overlap Opacity (%) Plugin Parameter](parameters/overlap-opacity-percent.md) - Minimap alpha when overlapping other windows (0=invisible,100=opaque).
