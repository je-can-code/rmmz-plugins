# Storage

This plugin will add the `_map` namespace to the system to hold its minimap data.

## Parent

- The system.

## Addition

The `_map` namespace.

## Save Section

`map`, when `J-Base-Save` is installed. Without it, the namespace saves inline with the system in the normal save.
