# notetag

* [Disable Refinement](notetags/disable-refinement.md) - The tag that keeps an equip out of refinement entirely.
* [Disallow Using as a Base](notetags/disallow-using-as-a-base.md) - The tag that stops an equip from being chosen as the base of a refinement.
* [Disallow Using as a Material](notetags/disallow-using-as-a-material.md) - The tag that stops an equip from being sacrificed as the material of a refinement.
* [Maximum Refinement Count](notetags/maximum-refinement-count.md) - The tag capping how many times an equip can be used as the base of a refinement.
* [Maximum Traits per Equip](notetags/maximum-traits-per-equip.md) - The tag capping how many combined traits an equip can hold through refinement.
