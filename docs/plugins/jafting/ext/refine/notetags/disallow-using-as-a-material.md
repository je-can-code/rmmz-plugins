# Disallow Using as a Material

## Description

Placing this tag onto equipment means it will be a disabled option when selecting a material equip to refine onto the
base. This most commonly would be used for preventing the player from sacrificing an equipment that is required for
story purposes.

## TAG USAGE

- Weapons
- Armor

## TAG FORMAT

`<notRefinementMaterial>`

## TAG EXAMPLES

`<notRefinementMaterial>`
This equip will be a disabled option when selecting a material equip to refine onto the base.
