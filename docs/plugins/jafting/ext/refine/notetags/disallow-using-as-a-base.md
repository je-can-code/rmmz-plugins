# Disallow Using as a Base

## Description

Placing this tag onto equipment means it will be a disabled option when selecting a base equip to refine. This most
commonly would be used by perhaps some kind of "fragile" types of equipment, or for equipment you designed explicitly as
a material.

## TAG USAGE

- Weapons
- Armor

## TAG FORMAT

`<notRefinementBase>`

## TAG EXAMPLES

`<notRefinementBase>`
This equip will be a disabled option when selecting a base equip to refine.
