# Storage

This plugin will add the `_refinement` namespace to the party to hold its refinement data.

## Parent

- The party.

## Addition

The `_refinement` namespace.

## Save Section

`refinement`, when `J-Base-Save` is installed. Without it, the namespace saves inline with the party in the normal save.
