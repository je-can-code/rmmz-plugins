# plugin-command

* [Call the Creation Menu Plugin Command](commands/call-menu.md) - Calls the JAFTING Creation scene.
* [Call the Study Shop Plugin Command](commands/call-study-shop.md) - Calls the scene for buying recipes. Scope it the same way the crafting menu is scoped.
* [Unlock Categories Plugin Command](commands/unlock-categories.md) - Unlocks all crafting categories matching the provided keys.
* [Lock Categories Plugin Command](commands/lock-categories.md) - Locks all crafting categories matching the provided keys.
* [Unlock Recipes Plugin Command](commands/unlock-recipes.md) - Unlocks all crafting recipes matching the provided keys.
* [Lock Recipes Plugin Command](commands/lock-recipes.md) - Locks all crafting recipes matching the provided keys.
* [Unlock All Categories Plugin Command](commands/unlock-all-categories.md) - Unlocks all implemented crafting categories.
* [Lock All Categories Plugin Command](commands/lock-all-categories.md) - Locks all implemented crafting categories.
* [Unlock All Recipes Plugin Command](commands/unlock-all-recipes.md) - Unlocks all implemented crafting recipes.
* [Lock All Recipes Plugin Command](commands/lock-all-recipes.md) - Locks all implemented crafting recipes.

# scene

* [Study Scene](scenes/jafting-study.md) - The scene for buying the knowledge of recipes from somebody who already has it.
