# Storage

This plugin will add the `_crafting` namespace to the party to hold its recipe and category data.

## Parent

The party.

## Addition

The `_crafting` namespace.

## Save Section

`crafting`, when `J-Base-Save` is installed. Without it, the namespace saves inline with the party in the normal save.
