# Storage

This plugin will add the `_jafting` namespace to the party to hold its salvage data.

## Parent

The party.

## Addition

The `_jafting` namespace.

## Save Section

`jafting`, when `J-Base-Save` is installed. Without it, the namespace saves inline with the party in the normal save.
