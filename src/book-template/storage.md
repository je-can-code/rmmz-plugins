# Storage

This plugin will add the `_template` namespace to the actors to hold its data.

## Parent

- All actors.

## Addition

The `_template` namespace.

## Save Section

`template`, when `J-Base-Save` is installed. Without it, the namespace saves inline with each actor in the normal save.
