# The Tag

## Description

Ever want to do something cool? Well now you can! By applying the appropriate tag across the various database
locations, you too can do cool things that only others with this plugin can do.

## TAG USAGE

- Actors
- Enemies
- Skills
- etc.

## TAG FORMAT

`<tag:VALUE>`
Where VALUE represents the amount to do.

## TAG EXAMPLES

`<tag:100>`
100 of something will occur when this is triggered.
